# Hammerspoon 2 integration

`upstream.json` pins an exact commit and verified archive checksum. `scripts/prepare-hammerspoon.sh` reconstructs `.build/hammerspoon2` from that archive, applies integration patches with `--fuzz=0`, deletes upstream shell files, and copies `Shell/` and `ShellCore/` into the synchronized `Hammerspoon 2/Atelier/` folder. It copies the shared `IPC/` transport into both app and CLI targets and checks that the app has exactly one `@main`. Reference checkouts and prototypes never participate.

Atelier owns the app entry point, lifecycle, menu, native welcome/permission windows, coexistence warning, and recovery UI. The excluded upstream files are `Lifecycle/Hammerspoon_2App.swift`, `Managers/ManagerManager.swift`, `Managers/SettingsManager.swift`, `Windows/OnboardingView.swift`, and `Windows/Settings/`. HS2's engine, modules, utilities, PermissionsManager, SpoonManager, AboutView, and ConsoleView stay upstream source. Sparkle remains linked and licensed, with no updater created or updater UI exposed. Releases remain manual.

## Adapter boundary

The same-named `ManagerManager` and `SettingsManager` classes deliberately replace excluded upstream classes. Their names satisfy calls from the retained engine, logger, SpoonManager, and Console. `SettingsManagerProtocol` still requires obsolete shell properties; those are inert compatibility members, never placement/relaunch settings. Configuration always comes from Atelier's canonical path. A compile failure in these shims is an upgrade signal to review their callers.

ManagerManager owns cleanup and context replacement. It retains the defaults object independently of the user's global variable, waits up to three seconds for its retiring helper to exit, and refuses replacement if teardown remains unsafe. Reload requests made inside JavaScript unwind before context replacement. Synchronous configuration errors keep the context alive; status/error presentation never owns cleanup. The native helper remains a separate process so private-API failure cannot crash the shell or independent scripts.

The identity patch derives IPC, CLI, AppleScript service, and URL identities from bundle metadata. The evaluation patch throws file errors with their source path/stack and clears the handled exception so later callbacks remain usable. Bundle/plist branding belongs to packaging. Source reconstruction does not patch SwiftUI bodies, managers, or the Xcode project. Verification evidence is recorded in ATE-36; integration fixes are maintained locally.

The IPC adapter replaces discovery through an unregistered launchd Mach service with a Unix socket. It preserves HS2's evaluation and log-streaming interfaces. Both peers authenticate the kernel-provided audit token against the same signing-team requirement as upstream, and require the same user ID. The socket lives in a private directory under the user's temporary directory, scoped by app identity and the explicit test configuration override. A held lock protects stale-socket cleanup; shutdown releases it before replacement. Framed JSON buffers are bounded. `hs.ipc.start()` remains opt-in; no persistent agent or service is installed.

## Selected revision and upgrade gate

The shell was first built and probed on 0.0.12 (`7a218dd`). The selected revision is `c0bd4d6ecfcb30b426b5b12a4292a95ad418f8ad`, the September 12 upstream main commit following PR #223. The latest published tag was still 0.0.12 on September 14; the commit pin was approved to include application-level AX delivery (#217), multi-notification watchers, the all-windows AX timeout (#219), and AX value bridging (#221).

The upgrade review covered unchanged lifecycle/managers and teardown, the added Node built-in installer/`util.inspect` and CommonJS registry, Console logging/selection changes, AX element-based watcher registration, and dependency lockfile changes. Groups now uses the selected revision's AX element and notification-array interface. Native Quick App transactions remain a gap adapter for launch without activation and All Desktops assignment.

For each upstream release, review lifecycle, runtime, Console, protocols, and dependency changes alongside the pin. Reconstruct with no fuzzy patch matches, run `mise run check` and `mise run build`, and follow the packaged lifecycle and manual workflow checks in [App/README.md](../README.md). A successful compile alone does not establish semantic compatibility. No whole-file fingerprint gate is required for upgrades.

The full gate includes a real-engine self-test and private lifecycle probe: partial/syntax failures, recovery, defaults pause/resume, relative modules/Spoons, URL dispatch, bounded helper shutdown refusal, native fallback diagnostics, and memory samples across 50 reloads. Signed packaging also probes AppleScript XPC and bundled/symlinked CLI IPC. Tests use an explicit private absolute `ATELIER_CONFIG_DIR`, load no real user configuration, and replace the Space helper with a nonmutating protocol fixture. Permission/coexistence checks require a disposable environment; real Desktop/window checks require disposable Desktops and saved test windows.

Packaging retains the complete built bundle, including its CLI, XPC service, Sparkle framework, signing capabilities, and licenses. Apple-signed builds retain hardened library validation; the ad-hoc CI probe alone relaxes library validation because its framework has no signing team. Ad-hoc probes skip same-team IPC and AppleScript XPC verification. The legacy migration helper remains bundled for now, but normal bootstrap never calls it.
